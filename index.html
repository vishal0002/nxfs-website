A gap we found in our own test harness.

Beta 2's workload had 368 write events, so the chunk list ended at 369. In Beta 3, balanced leaf splits pushed the workload to 384 events, which meant crash points 369 to 384 were never being swept. REPORT.md §4what Beta 3 does not show

What we haven't proven.

Untested

xfstests: never run.

Not once. It needs root and real block devices, and NXFS has only ever been qualified unprivileged on image files. Every qualification report says so.

UntestedPhysical power loss & real disks

Qualification ran in software on image files only. SIGKILL is not a power cut.

Untestedpjdfstest as root

5,694 assertions remain unevaluated.

UntestedBlock-device discard path

Discard logic has library tests, but the path down to a real block device was not exercised.

UnsupportedMulti-device boot reader

The boot reader handles single-device volumes only.

UnsupportedPool replace

Not available in Beta 3.

Not yet qualifiedBounded-memory fsck (R2)

Deferred. A call's transient heap is measured, not bounded.

Not yet qualifiedPOSIX compliance

Not claimed. The privileged half of pjdfstest hasn't run, and xfstests hasn't run at all.

Not yet qualifiedProduction use

Beta 3 is a beta. Don't put data on it that you can't lose.
